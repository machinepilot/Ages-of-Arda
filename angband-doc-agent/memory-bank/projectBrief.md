# Angband Project Brief

Angband is a free, single-player dungeon exploration roguelike game derived from the classics Moria and Umoria. It features turn-based gameplay, procedurally generated levels, permanent death, and complex character development.

The game is set in the world of Angband, the fortress of Morgoth (the "Black Enemy") from J.R.R. Tolkien's fictional universe. The player's goal is to descend through the dungeon, defeat increasingly difficult monsters, and eventually face Morgoth himself at the bottom level.

Angband has been in continuous development since 1990, with numerous variants and forks created by the community. The codebase is written primarily in C and is designed to be portable across multiple platforms including Windows, macOS, Linux, and various other systems.

Key features of the Angband codebase include:
- Modular design with separate systems for dungeon generation, monster AI, magic, combat, etc.
- Support for multiple display methods (ASCII, tiles)
- Extensible object, monster, and artifact systems
- Cross-platform compatibility
- Plugin architecture for variants and extensions

The Windows port of Angband provides native integration with the Windows operating system, including support for multiple graphical display modes, sound effects, and Windows-specific user interface elements.
