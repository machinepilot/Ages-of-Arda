# Ages of Arda Wiki Documentation

This directory contains the comprehensive documentation for the Ages of Arda project, an AI-driven roguelike variant of Angband set in Tolkien's world.

## Documentation Structure

The wiki is organized into the following sections:

### Main Pages
- `index.html` - Main landing page and introduction to the project
- `development-story.html` - The journey and evolution of the Ages of Arda project

### AI Architecture
- `ai-architecture/overview.html` - Overview of the AI system architecture
- `ai-architecture/mcp-integration.html` - Model Context Protocol (MCP) documentation
- `ai-architecture/multi-agent-framework.html` - Multi-Agent Framework documentation
- `ai-architecture/memory-bank.html` - Memory Bank System documentation
- `ai-architecture/lore-management.html` - Lore Management System documentation

### Assets
- `images/` - Directory containing diagrams and illustrations
- `styles/` - CSS styling for the wiki

### Navigation
- `sidebar.html` - Shared sidebar navigation component
- `sidebar.js` - JavaScript for dynamic sidebar loading
- `roguebasin-style.css` - RogueBasin-inspired styling for the wiki

## Style Guide

The documentation follows the RogueBasin wiki style guide with the following characteristics:
- Clean, readable layout with a focus on content
- Monospace fonts for code blocks and technical content
- Responsive design that works well on different screen sizes
- Consistent navigation across all pages
- Printer-friendly styling

## Contributing to Documentation

When adding new pages to the wiki:
1. Follow the existing HTML structure with proper navigation elements
2. Link the `roguebasin-style.css` stylesheet
3. Include the sidebar navigation component
4. Add the new page to the sidebar navigation
5. Ensure all code examples are properly formatted
6. Include diagrams where appropriate to illustrate concepts

## Building the Documentation

The documentation is static HTML and can be viewed directly in a browser. No build process is required.
