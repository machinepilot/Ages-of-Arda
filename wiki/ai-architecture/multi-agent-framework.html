Multi-Agent Framework

Specialized AI Agents Working in Concert

The Multi-Agent Framework is a core component of the Ages of Arda AI architecture, providing a structured approach to distributing AI responsibilities across specialized agents. Rather than relying on a single AI model to handle all aspects of gameplay generation, the framework orchestrates multiple purpose-built agents that collaborate to create a cohesive, rich gameplay experience.

Framework Architecture

The Multi-Agent Framework consists of a central orchestrator that coordinates communication between specialized agents, each responsible for different aspects of gameplay:

Agent Types and Roles

Narrative Agent

Responsible for generating story elements, quest descriptions, and narrative progression.

Key Responsibilities:

  • Quest generation and progression
  • Story arc development
  • Narrative consistency across gameplay sessions
  • Age-appropriate storytelling

Implementation:

# src/mcp/agents/narrative_agent.py
class NarrativeAgent:
    def __init__(self, lore_manager, memory_bank):
        self.lore_manager = lore_manager
        self.memory_bank = memory_bank
        self.current_arcs = {}
        
    async def generate_quest(self, player_context, location, difficulty):
        """Generate a new quest appropriate for the player's context"""
        # Retrieve relevant lore
        location_lore = self.lore_manager.get_location_lore(location)
        age_lore = self.lore_manager.get_age_context(player_context['age'])
        
        # Build prompt with constraints
        prompt = self._build_quest_prompt(
            player_context, 
            location_lore, 
            age_lore, 
            difficulty
        )
        
        # Generate quest via MCP
        quest_data = await self.mcp.generate_structured(
            prompt, 
            self.QUEST_SCHEMA
        )
        
        # Store in memory bank for consistency
        self.memory_bank.store_quest(quest_data)
        
        return quest_data

Character Agent

Manages NPC behaviors, dialogue, and character development.

Key Responsibilities:

  • NPC dialogue generation
  • Character personality consistency
  • Relationship development with player
  • Companion character behaviors

Implementation:

# src/mcp/agents/character_agent.py
class CharacterAgent:
    def __init__(self, lore_manager, memory_bank):
        self.lore_manager = lore_manager
        self.memory_bank = memory_bank
        self.character_memories = {}
        
    async def generate_dialogue(self, character_id, player_context, dialogue_type):
        """Generate dialogue for an NPC based on context"""
        # Get character data and history
        character_data = self.memory_bank.get_character(character_id)
        interaction_history = self.memory_bank.get_interaction_history(
            player_id=player_context['id'],
            character_id=character_id
        )
        
        # Get relevant lore
        character_lore = self.lore_manager.get_character_lore(
            character_data['name']
        )
        
        # Build dialogue prompt
        prompt = self._build_dialogue_prompt(
            character_data,
            character_lore,
            interaction_history,
            player_context,
            dialogue_type
        )
        
        # Generate dialogue
        dialogue = await self.mcp.generate_text(prompt)
        
        # Update interaction history
        self.memory_bank.store_interaction(
            player_id=player_context['id'],
            character_id=character_id,
            interaction_type='dialogue',
            content=dialogue
        )
        
        return dialogue

World Agent

Handles environment generation, descriptions, and world state management.

Key Responsibilities:

  • Location descriptions
  • Environmental storytelling
  • Weather and time effects
  • World state persistence

Implementation:

# src/mcp/agents/world_agent.py
class WorldAgent:
    def __init__(self, lore_manager, memory_bank):
        self.lore_manager = lore_manager
        self.memory_bank = memory_bank
        self.current_world_state = {}
        
    async def generate_location_description(self, location_id, player_context):
        """Generate a rich description of a location"""
        # Get location data
        location_data = self.memory_bank.get_location(location_id)
        
        # Get relevant lore
        location_lore = self.lore_manager.get_location_lore(
            location_data['name']
        )
        
        # Get environmental factors
        time_of_day = self.current_world_state.get('time_of_day', 'day')
        weather = self.current_world_state.get('weather', 'clear')
        season = self.current_world_state.get('season', 'summer')
        
        # Build description prompt
        prompt = self._build_description_prompt(
            location_data,
            location_lore,
            player_context,
            time_of_day,
            weather,
            season
        )
        
        # Generate description
        description = await self.mcp.generate_text(prompt)
        
        return description

Agent Orchestration

The Multi-Agent Framework includes an orchestration layer that coordinates communication between agents and ensures a cohesive gameplay experience:

# src/mcp/agents/orchestrator.py
class AgentOrchestrator:
    def __init__(self, mcp_client, memory_bank, lore_manager):
        self.mcp = mcp_client
        self.memory_bank = memory_bank
        self.lore_manager = lore_manager
        
        # Initialize agents
        self.narrative_agent = NarrativeAgent(lore_manager, memory_bank)
        self.character_agent = CharacterAgent(lore_manager, memory_bank)
        self.world_agent = WorldAgent(lore_manager, memory_bank)
        self.item_agent = ItemAgent(lore_manager, memory_bank)
        self.combat_agent = CombatAgent(lore_manager, memory_bank)
        
    async def process_game_event(self, event_type, event_data, player_context):
        """Process a game event using the appropriate agent(s)"""
        responses = {}
        
        if event_type == 'enter_location':
            # World agent handles location description
            responses['description'] = await self.world_agent.generate_location_description(
                event_data['location_id'],
                player_context
            )
            
            # Narrative agent checks for potential quests
            responses['quests'] = await self.narrative_agent.check_location_quests(
                event_data['location_id'],
                player_context
            )
            
        elif event_type == 'npc_interaction':
            # Character agent handles dialogue
            responses['dialogue'] = await self.character_agent.generate_dialogue(
                event_data['character_id'],
                player_context,
                event_data['dialogue_type']
            )
            
        elif event_type == 'combat_round':
            # Combat agent handles narration
            responses['narration'] = await self.combat_agent.generate_combat_narration(
                event_data,
                player_context
            )
            
            # Combat agent determines enemy tactics
            responses['enemy_action'] = await self.combat_agent.determine_enemy_tactics(
                event_data['enemy_id'],
                event_data['combat_state'],
                player_context['difficulty']
            )
            
        # Store event in memory bank
        self.memory_bank.store_game_event(event_type, event_data, responses)
        
        return responses

Inter-Agent Collaboration Patterns

Agents collaborate in several ways to create a cohesive gameplay experience:

  1. Sequential Processing: Events may be processed by multiple agents in sequence, with each agent adding its specialized contribution.
  2. Shared Memory: All agents access the same Memory Bank, allowing them to build upon each other's contributions.
  3. Context Enrichment: Each agent enriches the context with its specialized knowledge before passing to the next agent.
  4. Conflict Resolution: The orchestrator resolves conflicts when multiple agents have overlapping responsibilities.

Agent Communication Protocol

Agents communicate using a standardized protocol that includes:

  • Event Context: Information about the triggering game event
  • Player Context: Current player state, history, and preferences
  • World State: Current state of the game world
  • Response Format: Expected structure of the agent's response

Performance Considerations

The Multi-Agent Framework includes several optimizations to ensure responsive gameplay:

  • Parallel Processing: Independent agent tasks are processed concurrently
  • Caching: Common responses are cached to reduce redundant processing
  • Prioritization: Critical gameplay elements are processed before optional enhancements
  • Fallback Mechanisms: Pre-generated content is used when real-time generation would cause delays

Integration with Other Systems

The Multi-Agent Framework integrates with other core systems:

  • Model Context Protocol (MCP): Provides standardized communication with LLMs
  • Memory Bank: Stores and retrieves persistent context for consistent agent responses
  • Lore Management: Ensures all agent outputs are consistent with canonical lore
  • Game Engine: Translates agent outputs into gameplay elements
