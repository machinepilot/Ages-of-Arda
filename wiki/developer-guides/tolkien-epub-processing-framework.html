Introduction

The Tolkien ePub Processing Framework is a system for extracting structured data from J.R.R. Tolkien's works and integrating it into the Ages of Arda Memory Bank. This guide provides a comprehensive overview of the framework's architecture, components, and usage.

Framework Overview

At its core, the framework is a pipeline that transforms unstructured ePub content into structured, categorized entity data ready for use by the Ages of Arda game. The pipeline consists of several key components that work together to process the content.

Core Components

  • ePub Processor: Extracts text content from ePub files
  • Entity Extractor: Identifies named entities (characters, locations, etc.) in the text
  • Entity Consolidator: Merges duplicate entities and resolves references
  • Memory Bank Integrator: Formats entities for the Memory Bank structure
  • Schema Validator: Ensures entity data conforms to required schemas
  • Path Configuration: Manages file system paths across components

Component Details

ePub Processor

The ePub Processor handles the extraction of content from ePub files. It parses the ePub structure, identifies chapter boundaries, and extracts raw text content.

Key Features:

  • Handles multiple ePub format variations
  • Preserves chapter structure
  • Extracts metadata (title, author, publication info)
  • Handles special content (poems, songs, languages)
  • Outputs structured JSON for further processing

Entity Extractor

The Entity Extractor identifies named entities in the text using Ollama, a local LLM (Large Language Model) service. It categorizes entities by type and extracts relevant attributes.

Key Features:

  • Uses LLM for entity recognition with Tolkien-specific training
  • Categorizes entities (CHARACTER, LOCATION, ITEM, EVENT, etc.)
  • Extracts entity attributes (race, allegiance, significance, etc.)
  • Captures entity relationships
  • Records source context for traceability

Entity Consolidator

The Entity Consolidator merges duplicate entities, resolves aliases, and combines partial information from different mentions of the same entity.

Key Features:

  • Identifies duplicate entities using fuzzy matching
  • Resolves aliases and alternate names
  • Merges attributes from multiple mentions
  • Preserves all source references
  • Creates a consolidated entity database

Memory Bank Integrator

The Memory Bank Integrator transforms consolidated entities into the format required by the Ages of Arda Memory Bank system and organizes them by age and category.

Key Features:

  • Assigns entities to appropriate ages (First Age, Second Age, etc.)
  • Formats entities according to Memory Bank requirements
  • Creates appropriate directory structure
  • Generates descriptive content for Memory Bank entries
  • Establishes cross-references between related entities

Schema Validator

The Schema Validator ensures that all entity data conforms to the required JSON schemas before integration into the Memory Bank.

Key Features:

  • Validates entities against JSON schemas
  • Checks for required fields
  • Validates field types and formats
  • Generates validation reports
  • Supports schema versioning

Path Configuration

The Path Configuration system provides centralized path management for all components, ensuring consistency across different environments.

Key Features:

  • Defines paths for different environments (production, test, development)
  • Ensures cross-platform compatibility
  • Automatically creates required directories
  • Simplifies path handling in components
  • Provides utilities for path resolution and manipulation

Using the Framework

Prerequisites

Before using the framework, ensure you have:

  • Python 3.7 or later installed
  • Required dependencies installed (see requirements.txt)
  • Ollama service running locally (for entity extraction)
  • ePub files to process

Basic Usage

The framework can be used as a complete pipeline or as individual components.

Complete Pipeline

python processing/main.py --epub-dir "raw_inputs/epubs" --clean

Individual Components

# Process ePub files
python processing/epub_processor.py --input-dir "raw_inputs/epubs" --output-dir "processing/epub_content"

# Extract entities
python processing/entity_extractor.py --input-dir "processing/epub_content" --output-dir "processing/json_output"

# Consolidate entities
python processing/entity_consolidator.py --input-dir "processing/json_output" --output-dir "processing/consolidated"

# Integrate with Memory Bank
python processing/memory_bank_integrator.py --input-dir "processing/consolidated" --memory-bank-dir ".memory-bank"

Configuration

The framework can be configured through command-line options, environment variables, or configuration files. See the component documentation for specific configuration options.

Entity Categorization

Entity Types

The framework extracts and categorizes the following types of entities:

Entity Type Subtypes Attributes
CHARACTER PERSON, VALAR, MAIAR, MORTAL, ELF, DWARF, HOBBIT, OTHER name, race, allegiance, family, birth, death
LOCATION REALM, REGION, SETTLEMENT, LANDFORM, STRUCTURE, BODY_OF_WATER name, region, inhabitants, description, significance
ITEM WEAPON, JEWELRY, ARTIFACT, HEIRLOOM, CRAFTED_ITEM name, creator, powers, history, current_location
EVENT BATTLE, JOURNEY, MEETING, FOUNDING, DESTRUCTION, CREATION name, date, location, participants, outcome, significance
RACE ELDER, YOUNGER, CREATED, OTHER name, origin, traits, language, notable_members, settlements
LANGUAGE ELVISH, MANNISH, DWARVISH, ENTISH, BLACK_SPEECH, OTHER name, speakers, origin, writing_system, known_phrases

Age Assignment

Entities are categorized into the following ages:

  • First Age: Events from creation to the War of Wrath
  • Second Age: From the defeat of Morgoth to the defeat of Sauron by the Last Alliance
  • Third Age: From the defeat of Sauron to the War of the Ring
  • Fourth Age: Following the War of the Ring

Extending the Framework

The framework is designed to be extensible. Here are some common extension points:

Adding New Entity Types

To add a new entity type:

  1. Add the new type to the ENTITY_CATEGORIES dictionary in entity_extractor.py
  2. Create a schema for the new entity type in the schemas directory
  3. Update the Memory Bank Integrator to handle the new type
  4. Add tests for the new entity type

Adding New Data Sources

To add support for new data sources beyond ePub:

  1. Create a new processor module (e.g., pdf_processor.py)
  2. Implement the same interface as ePub Processor
  3. Add the new processor to the main pipeline
  4. Add tests for the new processor
