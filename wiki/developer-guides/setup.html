Development Environment Setup

Getting Started with Ages of Arda Development

This guide will walk you through setting up your development environment to contribute to the Ages of Arda project. The game is written primarily in C with various dependencies and tools to support AI integration and roguelike functionality.

Prerequisites

Before beginning, ensure you have the following installed on your system:

  • Git
  • C compiler (GCC 9+ or Clang 10+)
  • CMake (version 3.18+)
  • Python 3.8+ (for build scripts and AI integration)
  • SQLite 3.35+ (for the Memory Bank system)

Platform-Specific Requirements

Linux

sudo apt update
sudo apt install build-essential cmake python3 python3-pip libsdl2-dev libsqlite3-dev libcurl4-openssl-dev

macOS

brew update
brew install cmake python sdl2 sqlite curl

Windows

We recommend using MSYS2 or Windows Subsystem for Linux (WSL) for Windows development:

Using MSYS2:
  1. Download and install MSYS2
  2. Open MSYS2 MINGW64 shell and run:
pacman -Syu
pacman -S mingw-w64-x86_64-gcc mingw-w64-x86_64-cmake mingw-w64-x86_64-python mingw-w64-x86_64-sqlite3 mingw-w64-x86_64-curl mingw-w64-x86_64-SDL2

Setting Up Python Environment

The MCP system requires several Python packages. We recommend setting up a virtual environment:

python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt

Key Python dependencies include:

  • requests (for API communication)
  • numpy (for various calculations)
  • pytorch (for local AI model inference)
  • transformers (for text generation)
  • langchain (for LLM context management)

Cloning the Repository

git clone https://github.com/ages-of-arda/ages-of-arda.git
cd ages-of-arda

Building the Project

Ages of Arda uses CMake for build configuration. Follow these steps to build the project:

mkdir build
cd build
cmake ..
cmake --build .

The build process will create the main executable and necessary libraries in the build/bin directory.

Build Options

You can customize your build with various options:

cmake .. -DBUILD_TESTS=ON -DENABLE_ASSERTIONS=ON -DUSE_LOCAL_MODELS=OFF

Common options include:

  • BUILD_TESTS: Build test suite (ON/OFF)
  • ENABLE_ASSERTIONS: Enable additional runtime assertions (ON/OFF)
  • USE_LOCAL_MODELS: Use local AI models instead of API calls (ON/OFF)
  • DISABLE_SOUND: Build without sound support (ON/OFF)
  • MEMORY_DEBUG: Enable memory debugging tools (ON/OFF)

Running the Game

After building, you can run the game from the build directory:

cd bin
./ages-of-arda

On Windows with MSYS2, use:

cd bin
./ages-of-arda.exe

MCP Configuration

The Model Context Protocol (MCP) system requires configuration to work with AI services:

  1. Copy the example configuration file: cp config/mcp_config.example.json config/mcp_config.json
  2. Edit config/mcp_config.json to include your API keys and settings
  3. Configure your preferred AI model providers (OpenAI, Anthropic, self-hosted, etc.)

Note: For local development without API access, you can use the -DUSE_LOCAL_MODELS=ON build option along with appropriate model configurations in the MCP config file. This will use smaller, local models that don't require API keys.

Running Tests

If you built with -DBUILD_TESTS=ON, you can run the test suite:

cd build/bin
./run_tests

You can also run specific test categories:

./run_tests --gtest_filter="MemoryBank*"

Code Formatting

We use clang-format to maintain code style consistency. Before submitting a pull request, please format your code:

cd build
cmake --build . --target format

Alternatively, you can format individual files:

clang-format -i path/to/your/file.c

Debugging Tools

Memory Debugging

For memory debugging, we recommend:

  • Valgrind (Linux/macOS): valgrind --leak-check=full ./ages-of-arda
  • Address Sanitizer: Build with -DENABLE_ASAN=ON CMake option

MCP Debugging

To debug MCP interactions:

  1. Enable MCP logging: export MCP_DEBUG=1 (or set in config)
  2. Run with verbose output: ./ages-of-arda --verbose-mcp
  3. Check logs in logs/mcp_debug.log

Common Issues & Solutions

Build Fails with Missing Dependencies

Problem: CMake reports missing libraries.

Solution: Ensure all dependencies are installed. Check the CMake error message for specific missing libraries.

MCP Connection Issues

Problem: Game fails to connect to AI services.

Solution: Verify your API keys in config/mcp_config.json, check network connectivity, or switch to local models with -DUSE_LOCAL_MODELS=ON.

Slow Performance

Problem: Game runs slowly, especially when generating content.

Solution: Enable caching (-DENABLE_MCP_CACHING=ON), reduce AI model complexity in config, or switch to faster local models.
