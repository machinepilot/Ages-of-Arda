# Bag End

## Basic Information
- **Type**: LOCATION
- **Subtype**: STRUCTURE
- **Age**: Third Age

## Description
Bag End is a smial (hobbit-hole) located in Hobbiton in the Shire. It was the home of Bilbo Baggins and later of Frodo Baggins.

## Attributes
- **Region**: The Shire
- **Significance**: Home of Bilbo and later Frodo Baggins

- **Residence of**: [Bilbo Baggins](../CHARACTER/bilbo_baggins.md), [Frodo Baggins](../CHARACTER/frodo_baggins.md)
