# Frodo Baggins

## Basic Information
- **Type**: CHARACTER
- **Subtype**: HOBBIT
- **Age**: Third Age

## Description
Frodo Baggins is a hobbit who inherited Bag End from his uncle Bilbo Baggins. He set out from Bag End with his companions Samwise Gamgee and Peregrin Took on a journey that would ultimately lead to the destruction of the One Ring.
